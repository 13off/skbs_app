# Ручные объёмы инженера-сметчика v1

Ручная запись используется только как исключение, когда фактически выполненная работа не пришла из задачи мастера.

Правила:
- обязательны объект, работа, объём, единица, дата, причина и пояснение;
- дата не может быть в будущем;
- запись явно помечается как ручная;
- активная ручная запись автоматически участвует в накопительной ведомости «Объёмы»;
- физическое удаление из интерфейса и для authenticated-ролей запрещено;
- исключить запись из накопительной можно только аннулированием с обязательной причиной;
- аннулированная запись сохраняется в журнале вместе с автором и причиной.

Ручной ввод не заменяет основной поток `задача мастера → факт → проверка сметчиком`. Он закрывает только исключения и не должен использоваться как обычный способ внесения выполненных работ.
