3. Строгий Flutter analyzer.
4. Все Flutter-тесты с формированием покрытия.
5. Web release build.
6. Headless Chrome browser smoke.
7. Android debug APK.
8. Android release APK.

11. Формирование артефактов, размеров сборок, хешей APK и итогового автоматического отчёта.

- визуальное сравнение всех экранов в светлой и тёмной теме;
- коммерческий демонстрационный сценарий.

## Критерий результата

- `PASS`: все автоматические jobs зелёные, P0-дефекты не найдены.
- `CONDITIONAL PASS`: автоматическая часть зелёная, но ручная матрица не завершена.
- `FAIL`: упала хотя бы одна обязательная автоматическая проверка или найден P0-дефект.
