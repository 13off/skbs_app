## Подтверждённые дефекты

### QA-AUTO-001 — Edge Function кандидата не проходит Deno type-check

Файл:
`supabase/functions/recruitment-candidate-action/index.ts`.

Ошибки:

1. строка 208 — `storage_bucket` определяется на типе `never`;
2. строка 209 — `storage_path` определяется на типе `never`;
3. строка 298 — несовместимый generic-тип `SupabaseClient` при вызове `createDocumentsArchive`;
4. строка 410 — несовместимый generic-тип `SupabaseClient` при вызове `removeStoredFiles`.

Критичность: **P1 / release blocker**.

Риск: изменения функции оформления кандидата могут быть выпущены без статической проверки типов; возможны ошибки архива документов и удаления файлов.

### QA-AUTO-003 — дубли времени SQL-миграций

Проверено 141 SQL-миграция. Обнаружены два повторяющихся timestamp-префикса:

- `20260717203000`;
- `20260718150000`.

Каждый префикс используется более чем одним файлом, то есть затронуты четыре миграции.

Критичность: **P1 / release blocker**.

Риск: неоднозначный порядок миграций, конфликты локальной и production-истории, нестабильный deploy или различия схемы между окружениями.

## Технический долг и предупреждения

### Форматирование Dart

Строгий аудит `dart format --output=none --set-exit-if-changed lib test` обнаружил 351 файл, не соответствующий текущему canonical formatter.

Критичность: **P2**.

Это не ломает приложение, но противоречит цели чистого кода и создаёт шум в будущих рефакторингах. Массовое форматирование нельзя смешивать с функциональными исправлениями — его следует выполнять отдельным PR с полным визуальным и функциональным регрессом.

### Покрытие тестами

Line coverage составляет 27,42%. Существующие 741 тест успешно проходят, но значительная часть UI, интеграций и runtime-сценариев не покрыта автоматикой.

Критичность: **P2**.

### Android-зависимости

- `file_saver` использует Kotlin Gradle Plugin; Flutter предупреждает, что будущие версии могут прекратить сборку таких plugins без перехода на Built-in Kotlin;
- обнаружено 33 пакета с более новыми версиями, несовместимыми с текущими constraints;
- обновлять пакеты массово запрещено без отдельной ветки и полного регресса.

Критичность: **P2**.
