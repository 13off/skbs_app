# Импорт шаблона перед онлайн-редактированием

Онлайн-редактор работает только с DOCX, который находится во встроенных ресурсах приложения или в закрытом хранилище AppСтрой.

Для внешней ссылки или отсутствующего файла интерфейс сначала предлагает загрузить DOCX в AppСтрой. После успешного импорта редактор открывается автоматически.

Добавлены слоты для заявления на увольнение и соглашения на приобретение билетов.
