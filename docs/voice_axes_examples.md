# Голосовые оси — примеры

Поддерживаемые живые формулировки для формы задачи прораба:

- `оси 5-8 А-Г` → `5–8 / А–Г`
- `оси пять восемь а г` → `5–8 / А–Г`
- `оси с первой по пятую от а до г` → `1–5 / А–Г`
- `оси один два б` → `1–2 / Б`
- типичная ошибка iPhone ASR `оси один два 6` → `1–2 / Б`

Коррекция `6` → `Б` применяется только в узком контексте: после двух числовых осей, когда третьим последним значимым токеном распознана цифра `6` и буквенная ось отсутствует.
