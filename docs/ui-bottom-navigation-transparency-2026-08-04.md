# Нижняя навигация: прозрачность

Нижняя навигация во всех кабинетах использует общий `ProfessionalBottomNavigation`.

Правило интерфейса:

- панель должна оставаться стеклянной и реально полупрозрачной;
- тёмная тема не использует непрозрачный `0xFF`-фон;
- контент под панелью должен слегка просматриваться через размытие;
- на пустом фоне панель остаётся графитовой, но не превращается в чёрную плашку;
- выбранная вкладка сохраняет синюю подсветку;
- роли, маршруты и логика вкладок не зависят от оформления панели.
