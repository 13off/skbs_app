# Надёжность маршрута сотрудника

Рабочий день сотрудника использует нативную фоновую геолокацию Android.
Неотправленные координаты и события разрыва сохраняются локально до
подтверждения сервера. Руководитель видит записанные и вычисленные периоды,
когда координаты не поступали.

Профиль сотрудника открывается из шапки, а в настройках сотрудника доступны
только личные параметры интерфейса, уведомлений и геолокации рабочего дня.

Сборка APK этим изменением не запускается.
